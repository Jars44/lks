# Esemka Recipes — Android client view

## Status
Spec PDF + Postman collection + user credentials + Android UI resource assets.
The prebuilt .NET backend lives at `../Backend/` (see `../Backend/README.md`).

## Contents
- `EsemkaRecipes_TP.pdf` — the task project spec for the Android client
- `EsemkaReceipt.API.postman_collection.json` — Postman collection for the API
- `UserCredentials.xlsx` — pre-populated user accounts for the app
- `Resources/` — Android UI resources (icons, mockups, profile images)

## Caveats
- No Android client source code in this tree. Only the supporting spec + assets.
- Backend is a prebuilt .NET publish — see `../Backend/README.md`.
